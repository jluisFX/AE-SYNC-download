# Versão 2.01

- Cache persistente em disco e modo offline para frames preparados.
- Escolha inicial de uma composição livre entre instâncias ativas.
- Render direto sem abrir a página Deliver, com áudio nos três perfis.
- Redução de cópias de imagem no broker.
- Script para preparar o AE SYNC em uma composição Fusion vazia.
- Instalador Windows com três idiomas, detecção do After e desinstalação.

Limite conhecido: o After pode sinalizar outras composições como alteradas. Nesses casos, o AE SYNC invalida os resultados afetados pela sinalização para preservar a correção da imagem.
